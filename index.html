Fluxo de Decisão para o Vendedor
1
Consultar CPF
Consulta obrigatória no Serasa para TODOS os novos clientes, independente do produto.
2
Identificar Cidade
Verificar o Tier da cidade do cliente: RESTRITO, MODERADO ou PADRÃO.
3
Verificar Produto
Cada produto tem threshold específico por tier. Consultar a Matriz de Produtos.
4
Checar Bloqueios
Pefin + Protesto simultâneos = bloqueio absoluto, independente do score.
5
Aplicar Decisão
Aprovado direto · Zona Cinza → gestor (24h) · Negado → encerrar atendimento.
Legenda das Decisões
✅ APROVADO
Score ≥ threshold da cidade + produto. Prosseguir com a venda normalmente. Registrar consulta no sistema.
🟡 ZONA CINZA
Score entre o mínimo e o ideal. Encaminhar para aprovação manual do gestor comercial. Prazo: até 24h.
❌ NEGADO
Score abaixo do mínimo absoluto para aquela cidade/produto. Não prosseguir. Registrar tentativa no sistema.
🔒 BLOQUEIO ABSOLUTO
Cliente com Pefin ATIVO + Protesto em cartório simultaneamente. Negado independentemente do score Serasa.
Calibração — Base Histórica
As regras foram calibradas com base em 984 contratos cancelados por inadimplência consultados no Serasa em Abril/2026.
Score Serasa médio dos cancelados: 418 (RESTRITO) · 446 (MODERADO) · 475 (PADRÃO)
Os thresholds foram definidos acima da média histórica de cada tier para criar margem de segurança na entrada.
A regra base da empresa (400/400) é mantida como piso mínimo. Para cidades e produtos críticos, o threshold é elevado.
